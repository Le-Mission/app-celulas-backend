# Privacy (LGPD)

## Data Collected

| Data | Source | Purpose |
|------|--------|---------|
| Email, Name, Avatar | Clerk | User identification |
| Church name, slug | App | Organization management |
| Member names, emails | App | Church membership |
| Cell names, schedules | App | Cell management |
| Payment data | AbacatePay | Subscription billing |
| CPF/CNPJ | AbacatePay | Tax identification |
| Files | Wasabi S3 | Document storage |
| Audit logs | System | Compliance |

## Base Legal

- **Contract execution**: Service delivery to paying customers
- **Legitimate interest**: Security, fraud prevention
- **Consent**: Marketing communications (if applicable)

## Retention

- User data: Retained while account is active
- Payment data: Retained per financial regulations
- Audit logs: Configurable per plan entitlement
- Files: Retained while subscription is active

## Deletion

- User can request data export
- Account deletion deactivates (does not immediately purge)
- Financial records retained per legal requirements

## Data Export

Planned feature: users can request data export via API.
